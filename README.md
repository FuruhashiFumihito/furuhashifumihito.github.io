# Research Homepage

古橋郁人の研究用ホームページ

## ファイル構成
- `index.html` - 日本語トップページ
- `index-e.html` - 英語トップページ
- `style.css` - スタイルシート

## ローカルでの確認
```bash
open index.html
```

## GitHub Pagesでの公開方法
1. このリポジトリをGitHubにpush
2. Settings → Pages → Source: Deploy from a branch
3. Branch: main, / (root) を選択
4. Save
